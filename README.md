## Usage

The notes are written for Obsidian. Either open this folder directly as an Obsidian vault, or place the files inside an existing vault.

The following Obsidian community plugins are required for the notes to render correctly:

- **Automatic Table Of Contents** — renders the `table-of-contents` block at the top of each chapter.
- **Callout Manager** — provides the custom callout types used in these notes (e.g. `[!Comparison]`) that are not native to Obsidian.
- **TikZJax** — renders embedded TikZ diagrams.
- Built-in Obsidian features (standard callouts, wikilinks) are also assumed.

In other Markdown environments the notes remain readable as plain text, but rendering will be incomplete.
